Учитель Слов

Интерактивное веб-приложение для заучивания слов и словарных пар с системой интервального повторения, поддержкой нескольких словарей и мини-играми. Работает прямо в браузере без серверов и регистрации.
Основные возможности
 * 4 режима работы:
   * ⚡ Match Madness (Пары): Игра на скорость на сопоставление слов и переводов.
   * 🎯 4 Варианта: Классический тест с выбором правильного ответа из четырех вариантов.
   * 🎴 Флеш-карточки: Карточки для самопроверки с адаптивным алгоритмом показа и возможностью пропуска.
   * ⌨️ Ввод с клавиатуры: Тренажер правописания с проверкой через расстояние Левенштейна.
 * Умная система рейтинга:
   * Правильный ответ увеличивает рейтинг слова (+1).
   * Ошибка сбрасывает ненулевой рейтинг до нуля, а при нуле и ниже уменьшает его вплоть до -10.
   * Слова с высоким рейтингом автоматически уходят из активной ротации.
 * Управление словарями:
   * Загрузка нескольких словарей одновременно через JSON-файлы или вставку текста.
   * Автоматическое удаление пустых словарей.
   * Полный бэкап всех словарей и прогресса в один файл.
   * Фильтрация и очистка/экспорт выученных слов по порогу правильных ответов (N).
Формат данных (JSON)
Приложение поддерживает два формата JSON:
 * Одиночный словарь (массив пар):
   [
  ["apple", "яблоко", 0],
  ["cat", "кот", 5]
]

 * Бэкап всех словарей (объект):
   {
  "Английский": [
    ["dog", "собака", 2]
  ],
  "Немецкий": [
    ["Haus", "дом", 1]
  ]
}

Запуск
 * Скачайте или скопируйте исходный HTML-файл.
 * Откройте его в любом современном браузере (поддерживаются ПК и мобильные устройства).
 * Загрузите готовый словарь или создайте его через импорт.
